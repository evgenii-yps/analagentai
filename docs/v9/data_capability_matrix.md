# Возможности данных

| Источник | Факт кода | Ограничение и незнание |
|---|---|---|
| Trades (`src/collectors/trades.py`, `src/core/db.py`) | последние 1000, дедупликация по `(instrument_id, trade_id)`, side может отсутствовать | курсор/непрерывность не установлены; потеря и запаздывание возможны; агрессивная сторона требует подтверждения семантики CCXT/биржи |
| `trade_flow_1m` (`db/init.sql`, `scripts/retention.py`) | count, buy/sell volume и count, VWAP; завершённые минуты, конфликт не обновляет | amount хранится как пришёл; единицы не нормализованы; поздние сделки не изменяют уже записанную свёртку; нет гарантии пустых минут или полноты |
| OHLCV (`src/collectors/ohlcv.py`, `src/core/db.py`) | limit 200; UPSERT по инструменту, интервалу и времени | текущая свеча может обновляться; время доступности и историческая непрерывность отдельно не доказаны |
| Стакан (`src/collectors/orderbook.py`, `src/core/db.py`) | периодические снимки bids/asks и spread | в этом пути нет проверки последовательности дельт и восстановления непрерывной книги |
| Funding и OI (`src/collectors/futures.py`) | отдельные запросы; ошибки логируются; OI берётся из нескольких разных полей | расписание funding, единицы OI, полнота и ликвидации не подтверждены |
| Registry (`src/core/instruments.py`, `src/core/config.py`) | заданные пары spot/swap; по умолчанию одна пара | автоматические профили и разрешения на новые инструменты не доказаны; проверить потребителей на жёсткие предположения |
| Хранение и replay (`scripts/retention.py`, `backtest/*`) | сырьё подлежит retention; есть свёртки и replay | доступность удалённого сырья, корректность backfill, timestamp наблюдения и отсутствие look-ahead для v9 не установлены |
