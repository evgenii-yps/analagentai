## 4. Decision Agent — арифметика решения

Decision Agent сам рынок не анализирует — он только взвешивает выводы трёх агентов. Формула балла:

```
balance = Σ(direction_i × confidence_i × weight_i) / Σ(weight_i × confidence_i)
  где direction: bullish=+1, bearish=−1, neutral=0
```

Учитываются только свежие выводы с направлением. В расчёте участвуют **3** агент(а/ов) (минимум по конфигу: 2).

| Агент | Сигнал | dir | confidence | weight | dir×conf×w | w×conf |
|---|---|---|---|---|---|---|
| market | bullish | +1 | 0.5707 | 1.00 | +0.5707 | 0.5707 |
| liquidity | bullish | +1 | 0.3913 | 1.00 | +0.3913 | 0.3913 |
| futures | neutral | +0 | 0.0340 | 1.00 | +0.0000 | 0.0340 |
| **Σ** | | | | | **+0.9620** | **0.9960** |

**Балл = +0.9620 / 0.9960 = `+0.9659`** (диапазон −1…+1).

Порог решения: **±0.30**.
- если балл > +0.30 → **buy**
- если балл < −0.30 → **sell**
- иначе → **wait**

Балл `+0.9659` → итог **BUY**.

**Согласованность агентов** = |2−0| / 3 = `0.67` (1.0 = все смотрят в одну сторону).
**Вероятность** = min(|балл| × (0.5 + 0.5×согл.), 1.0) = min(0.9659 × 0.83, 1.0) = **0.8049**.
